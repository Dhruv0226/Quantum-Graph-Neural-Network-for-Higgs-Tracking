# Quantum Graph Neural Network for Higgs Tracking

A research-oriented machine learning project that explores the use of **Quantum Graph Neural Networks (QGNNs)** for particle trajectory reconstruction and Higgs particle tracking in high-energy physics datasets.

The project leverages graph-based deep learning techniques to model particle interactions and improve tracking accuracy by representing detector data as graphs.

---

## Features

- Graph-based representation of particle detector data
- Graph preprocessing and feature engineering
- Quantum Graph Neural Network implementation
- Particle trajectory reconstruction
- Model training and evaluation
- Performance analysis using graph learning techniques

## Workflow

1. Load high-energy physics dataset.
2. Convert detector information into graph structures.
3. Perform graph preprocessing and feature extraction.
4. Train the Quantum Graph Neural Network.
5. Evaluate the trained model.
6. Analyze particle tracking performance.

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Quantum-GNN-Higgs-Tracking.git
```

Move into the project directory

```bash
cd Quantum-GNN-Higgs-Tracking
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the training script

```bash
python train.py
```
